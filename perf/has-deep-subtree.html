Notes
  • Two checks use #subject:has(.first):has(.second). Both match the first child; the second lookup triggers subtree-filter construction.
  • Evaluation includes the browser work needed for the style read and optional layout flush. DOM creation, attachment and removal are timed separately.
  • Keep this tab in the foreground and close DevTools for timing. Browser timer precision and GC affect results.
  • The fix removes recursion. It still visits the subtree. Crash thresholds depend on stack size and style-thread scheduling; this page does not change Firefox preferences.
  • URL settings: depth, leaves, siblings, mode (compare, 0, 1, 2, custom), count, repeats, warmups, flush (layout-color or color), pause, slow, build, stress (1 or 0). Settings load without running a trial.
